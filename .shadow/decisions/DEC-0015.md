## Context

Map generation, validation, preview, and region rendering must be reproducible and reviewable, while generated previews and one-off experiments should not become source assets.

## Decision

Keep the map toolchain source under tracked `scripts/map-gen/` and expose it through `npm run map:*` scripts. Treat `temp/` as ignored scratch output for generated previews, region renders, templates, and experiments, not as source for maintained tooling.

## Rationale

`package.json` points map commands at `scripts/map-gen/cli.ts` and `scripts/map-gen/region/region-map.ts`. The tracked toolchain contains generators, exporters, validators, preview rendering, region rendering, and shared map-generation utilities.

## Consequences

Tooling changes are reviewed like normal source changes. Map previews and generated scratch artifacts should not be committed unless a separate workflow explicitly promotes them to source assets.

## Unknowns

No decision record identifies every historical generator that lived under ignored scratch paths, so this record only describes the current tracked toolchain boundary.
