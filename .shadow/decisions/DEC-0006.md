## Context

Pokemon, moves, items, encounters, trainers, quests, and related content share
stable shapes and many cross-references.

## Decision

Represent game content as typed, declarative TypeScript data under
`frontend/src/data/`. Keep executable game logic in battle, systems, managers,
or scenes.

## Rationale

Shared interfaces define the data contracts, while files such as the fire move
catalog export static records. Repository guidance explicitly describes data
files as pure and side-effect free.

## Consequences

Content additions follow existing interfaces and barrel exports. Data integrity
checks can validate references and ranges independently from presentation.
