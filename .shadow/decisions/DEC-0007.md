## Context

Maps combine tile layouts with typed metadata for encounters, NPCs, trainers,
objects, warps, and spawn points.

## Decision

Define map tile layouts as character-grid rows parsed into tile numbers, with
metadata stored in TypeScript `MapDefinition` objects. Use the repository map
commands backed by tracked `scripts/map-gen/` source for generation, preview,
composition, region rendering, and validation.

## Rationale

`parseMap` owns the character-to-tile mapping, and Route 1 demonstrates a parsed
row grid combined with typed map metadata. Package scripts expose the dedicated
map toolchain from tracked source. Generated preview and region-render outputs
still belong under ignored `temp/` scratch paths.

## Consequences

Map edits must preserve row dimensions, known tile characters, metadata
contracts, and warp connectivity. Validation and previews accompany map changes.
