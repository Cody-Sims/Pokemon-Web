## Context

Scenes and managers need to announce state changes without retaining direct
references to one another.

## Decision

Use the singleton `EventManager` as the event bus for cross-scene communication.
Prefer typed event names where the shared `EventMap` defines a payload.

## Rationale

The manager implements registration, emission, removal, tagged cleanup, and
reset behavior. Scene code emits map and progression events, and integration
tests verify listener behavior.

## Consequences

Cross-scene notifications use event contracts instead of direct scene coupling.
Owners must remove or tag listeners so scene restarts do not retain callbacks.
